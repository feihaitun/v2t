首次连接：只需设置一次
  1. 点击上面的按钮，在平常登录抖音的 Chrome 中使用这个网页。
  2. 在 Chrome 地址栏输入 chrome://extensions，打开「开发者模式」。
  3. 点击「加载已解压的扩展程序」，选择项目里的 chrome-connector 文件夹。
  4. 刷新本机网页，看到「Chrome 已连接」就可以开始。抖音需要保持登录。

连接器只在此开关开启的任务中读取目标抖音视频资料。账号 Cookie 留在 Chrome 中；视频地址和字幕只传给本机工具。用完会自动关闭它新开的目标视频标签页。

      文字稿
      它是怎么工作的？（大白话）

      从视频里拿文字，现在有两个来源：平台现成的字幕、视频里的声音。普通模式找不到平台字幕时，会在本机转录声音；「只下载平台原文件」模式会先停在视频结果，你可以点「用已下载视频转录」，不用重新下载。（画面上印着的字暂时还不读。）

      1. 认链接：看是哪个平台，短链接先展开，去掉分享人的跟踪参数。
      2. 找现成字幕：普通模式先查平台字幕，找不到再转写。原文件模式下，YouTube 和 B站优先使用 Chrome 登录状态查找中英文字幕，分别保存平台原文件；抖音可开启专用的 Chrome 连接器。找到字幕后仍会下载完整视频。
      3. 拿视频/音频：每个平台按「从快到稳」的顺序试几种办法，前一种失败就自动换下一种。你这个链接具体会试哪几种，上面「预计步骤」里写着：
        • 抖音：专用浏览器（从不登录）打开视频页，让页面自己去要视频地址 → 换一个全新的访客身份再试 → yt-dlp（备用，目前无效）→ 第三方解析网站（默认关闭）
        • 小红书：用「手机版网页」读视频地址（不登录、不带 cookie）→ 模拟 iPhone 的浏览器 → yt-dlp
        • B站：原文件模式先用 Chrome 登录状态下载视频，再试访客下载；普通模式先访客下载音频
        • YouTube：原文件模式先用 Chrome 登录状态下载视频，再试访客下载；普通模式使用访客下载
      4. 抽音频：ffmpeg 把声音抽出来。
      5. 语音转文字：本机的 Whisper 模型转写，音频不上传。
      6. 整理输出：生成 md / srt / txt / json，并记下这次是怎么拿到的。

      关闭 Chrome 开关时，原来的访客流程保持不变。开启后由连接器使用正常登录的 Chrome 打开目标视频，不再把 Cookie 搬到临时浏览器。下载完成后可以在结果区点「下载视频」「下载 srt」，或者点「打开文件夹」。所有记录都在 data/jobs/任务编号/。

# Chrome 连接器

版本：**0.2.0-rc.1（预览版）**。需要桌面版 Chrome 和正在运行的 v2t 服务。

设置一次后，全部操作都在本机网页完成。

1. 在平常登录抖音的 Chrome 打开 `http://127.0.0.1:8765`。
2. 在 Chrome 打开 `chrome://extensions`，开启「开发者模式」，点「加载已解压的扩展程序」，选择本目录。
3. 刷新本机网页，开启「使用已登录的 Chrome 获取抖音视频和字幕」，确认显示「Chrome 已连接」。
4. 粘贴链接；要视频画面就在「选项」勾选「下载完整视频」。点击开始。
5. 完成后在结果区点「下载视频」和「下载 srt」，或者「打开文件夹」。原字幕不存在或不可获取时，SRT 来自本机转写，页面会标明来源。

更新代码后，在 `chrome://extensions` 中重新加载本扩展，再刷新工具网页。暂时停用可关闭网页开关；卸载可在扩展管理页点击「移除」。

## 权限和范围

连接器只申请抖音网页的脚本访问以及本机工具页的内容脚本权限，没有 Cookie、浏览历史、调试器或全站访问权限。不会读取、复制、导出或保存账号 Cookie。只有网页任务明确开启 `douyin_chrome` 时才打开一个目标视频标签页；它与平常使用的 Chrome 共享登录状态，用完关闭，不动原来的标签页。

抖音页面返回的视频资料和字幕、或播放器已加载的媒体地址，通过本机网页同源接口交给本机程序。请求限定视频编号，使用一次性令牌，35 秒到期。服务器保持原来的跨域限制；不接受抖音网页或其他网站直接调用。原始详情、临时媒体地址不会写入任务记录。媒体下载不携带账号 Cookie。

请保持本机网页在 Chrome 中打开。后台任务可在应用内浏览器查看，但首次连接和任务开始建议在 Chrome 的本机网页进行。此版本连接默认端口 8765。未连接时网页会明确提示；运行中连接丢失会自动回退到原来的访客流程。

## 结构

- `local-page.js`：只在本机工具页面领取明确的任务、报告连接状态。
- `background.js`：在现有 Chrome 中新开目标视频、安装本次临时读取脚本、结束后清理。
- `page-capture.js`：只读取目标视频详情接口及已加载媒体，保留视频和字幕字段；不伪造签名，不尝试破解验证。
- `v2t/chrome_bridge.py`：验证目标编号和来源域名、解析字幕、下载媒体、合并独立画面和声音。

安装后仅有连接权限，不保证每条视频都有原字幕，也不保证平台不会限制自动化访问。插件本身不解决账号封禁或平台验证。

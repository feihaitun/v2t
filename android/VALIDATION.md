## 会话导入与持久保存

- Python → Android RSA-OAEP + AES-GCM 互通通过；篡改密文拒绝导入，已有会话保留。
- Cookie 导入采用 Android Keystore 加密和同步磁盘提交，四个平台批次在校验后一次提交。
- 使用隔离测试存储验证了：手动导入会话、网页登录快照在强制结束进程后仍可恢复；网页登录快照不依赖 WebView 继续持有原 Cookie。
- USB 大数据传输使用无 PTY 的 ADB shell 标准输入，先验证整份密文 SHA-256，再原子移动到接收文件。570 KB 测试传输完整。
- 已从当前 Mac Chrome 的当前配置，成功同步 B 站、X、小红书、YouTube 的现有登录态到连接的手机。同步输出只有平台名和结果，没有 Cookie 值。保存成功不等于所有平台服务器都永久接受该会话；过期时重新同步或登录。
- 最终覆盖安装并强制结束 App 后，B 站官方登录状态接口仍返回已登录，随后成功取得 928 段平台字幕。其余三平台本轮未重新做带登录态的服务器有效性验证。
